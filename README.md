# Curlie (curlie)

Curlie is a multilingual, human-edited web directory and the official successor to the Open Directory Project (ODP), also known as DMOZ. After the DMOZ directory was shut down in March 2017, the editor community relaunched the project as Curlie to continue cataloging websites by topic across more than 90 languages.

This repository captures the APIs, developer tools, and machine-readable API artifacts for Curlie.

## APIs

No public developer APIs have been documented for Curlie. Unlike the original DMOZ project, which historically distributed weekly RDF dumps of its directory data, Curlie does not publish a documented public API or open data feed at this time. Contributions welcome.
